# SLSD Runtime

المستودع العام الصغير الخاص بملفات تشغيل Shadowrocket لمشروع SLSD الخاص.

## الملفات

- `ios-location-spoofer-dynamic.sgmodule` — وحدة Shadowrocket القابلة للاستيراد.
- `location-spoofer-dynamic.js` — محرك تعديل استجابة Apple WLOC.
